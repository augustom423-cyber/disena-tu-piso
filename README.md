# Diseña tu piso · Garaje Tu Estilo

Diseñador de pisos de losas modulares para garajes y pads: forma y medidas del espacio, puertas y ventanas, losa y colores, rampas, autos y muebles, vista 2D y 3D, y cotización por WhatsApp.

Este repositorio solo publica el diseñador (`index.html`) con GitHub Pages para insertarlo en la página de Wix.
